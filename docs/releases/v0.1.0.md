# VPSKit v0.1.0

VPSKit首个公开版本，面向个人Debian 13 amd64 VPS，以低资源、可回滚和安全客户端交付为目标。

## 主要功能

- Xray `v26.3.27`：VLESS REALITY Vision TCP入站；
- sing-box `v1.13.14`：Hysteria2 TLS UDP入站；
- TCP/UDP可使用同一个数字端口；
- balanced与Reality-only两种Profile；
- Cloudflare DNS-01，支持ZeroSSL与Let's Encrypt；
- Mihomo、sing-box、分享链接、二维码和带清单的客户端ZIP；
- 中文固定版本安装向导和管理菜单；
- REALITY目标扫描、事务化变更、备份/恢复、更新、证书续期和中断恢复。

## 安装

正式仓库确定后，在发布tag前把下面的占位地址替换为真实地址：

```bash
curl --fail --location --proto '=https' --tlsv1.2 \
  --output install.sh \
  'https://github.com/filence/vpskit/releases/download/v0.1.0/install.sh'
sudo bash install.sh
```

不推荐 `curl | bash`。安装器固定版本与归档SHA-256，并继续验证归档内的Ed25519签名清单。

## 已验证范围

- Debian 13 amd64实机；
- Clash Verge与Hiddify的REALITY/Hysteria2；
- 固定版本Mihomo、sing-box与Xray客户端自动化链路；
- 安装、诊断、证书、实例变更、客户端修订、备份/恢复、自更新、卸载重装和重启持久化；
- 固定Bootstrap在受保护恢复快照后的从零重装、双协议回环、重启复测和新客户端配置四项GUI验收。

Debian 12、Ubuntu 24.04和arm64仅为目标支持，不应表述为首版已验证平台。

## 升级与迁移

这是首个稳定版本，没有上一稳定版本的升级承诺。实验lab安装不得直接视为生产升级来源；使用签名包执行升级前必须先运行doctor并创建备份。

状态schema 1至4可由当前程序迁移到schema 5，但正式生产迁移仍应按备份、更新、doctor和客户端修订检查顺序执行。

## 回滚与恢复

- 实例变更会返回 `previous_backup_id`；
- `vpskit restore <backup-id> --yes` 恢复受管配置；
- `vpskit rollback <transaction-id> --yes` 回滚更新事务；
- `vpskit recover` 处理受管的未完成事务；
- 初始安装或更新失败时，事务引擎尝试恢复旧配置、旧二进制和服务状态。

客户端确认新修订可用前不要删除回滚点。

## 已知限制

- 首个Bootstrap只允许Debian 13 amd64；
- 不自动修改SSH、内核、BBR、本机防火墙或云安全组；
- 不提供Web面板、数据库或常驻HTTP订阅；
- 静态客户端文件不会自动更新，`config_revision`变化后必须重新导出并导入；
- 云安全组、DNS状态和真实公网客户端仍需每台部署单独确认；本次Debian 13 amd64实机已经确认；
- 尚未完成24小时稳定性、并发压力、Debian 12、Ubuntu和arm64云实机矩阵；
- 当前许可证结论是工程边界，不是正式法律意见。
