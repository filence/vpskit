# VPSKit v0.1.1

v0.1.1 是 Renderer 与运维基础版本，保持 Xray REALITY + sing-box Hysteria2 的现有部署语义，为后续自动订阅建立稳定产物边界。

主要变化：

- 状态升级至 schema 6，增加稳定节点身份和显示元数据；
- Mihomo 改为结构化 YAML 渲染并加入 golden 测试；
- Mihomo、sing-box 和分享链接接入统一 Artifact Set；
- 新增 Renderer capability 与 static Publisher；
- 新增 `node show/modify`、`migrate check/plan/apply`、`cleanup plan/apply`、`system inspect` 和脱敏 support bundle；
- 客户端产物增加确定性元数据、修订和摘要；
- 修复配置更新后已运行 systemd 服务未重启的问题；
- 发布包补充 go-yaml 许可证、NOTICE 和 SBOM 记录。

固定兼容基线：

- Xray `v26.3.27`；
- sing-box `v1.13.14`；
- Mihomo `v1.19.29`；
- Clash Verge Rev `v2.5.2`；
- v2rayN `v7.23.1` 源码解析基线，Win11 实机验收版本 `v7.23.4`。

详细证据见 [v0.1.1 实施验收报告](../V0.1.1_ACCEPTANCE.md)。自动订阅仍属于 v0.2.0，不在本版本内宣称完成。
