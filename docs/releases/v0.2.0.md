# VPSKit v0.2.0

`v0.2.0` 是面向个人 VPS 的功能收口版本。在保留 Xray VLESS REALITY 与 sing-box Hysteria2 双入口的基础上，增加自动订阅、受管分流规则、日常诊断和经过隔离的 Hysteria2 可选组件。

## 主要能力

- Cloudflare Workers/KV 自动发布 Mihomo 完整配置、v2rayN 节点订阅与 manifest；支持 ETag、条件 GET、读 Token 轮换/吊销、远端回读与静态导出回退；
- 受管 ACL4SSR 与 anti-AD 规则缓存。规则刷新采用“完整下载、限额/哈希校验、原子激活”；源失败不会破坏当前订阅；
- 精确域名白名单，以及域名、域名后缀、IP CIDR 的 `DIRECT / PROXY / REJECT` 自定义规则；所有修改均有备份、修订递增和自动发布；
- `doctor --fix`、清理计划、系统检查、脱敏支持包、迁移预演与统一 `instances[]` Adapter 生命周期；
- Fail2ban SSH 白名单，仅管理 VPSKit 自有覆盖文件；
- Hysteria2 能力/性能检查、保守 `conservative-2mib` UDP buffer 档、默认关闭的 Salamander，以及独立 nftables/systemd 组件的端口跳跃；
- 端口跳跃仅将指定 UDP 范围重定向到既有 Hysteria2 端口，不接管通用防火墙，也不向 sing-box 授予 `CAP_NET_ADMIN`。

## 安装

```bash
curl --fail --location --proto '=https' --tlsv1.2 \
  --output install.sh \
  'https://github.com/filence/vpskit/releases/download/v0.2.0/install.sh'
sudo bash install.sh
```

安装器固定该 Release、归档 SHA-256 和签名清单。不要执行 `main` 分支脚本或不固定版本的 `curl | bash`。完整步骤见[安装与首次使用](../INSTALL.md)。

## 从 v0.1.0 升级

不要再次运行初始安装器。先在现有节点执行 `sudo vpskit doctor` 和 `sudo vpskit backup`，再使用本 Release 的签名包执行 `vpskit update self`。升级会按状态 schema 执行迁移；任何写入失败会恢复本次受管变更。升级后执行：

```bash
sudo vpskit doctor
sudo vpskit instance list
sudo vpskit subscription status
```

如果尚未配置 Cloudflare 订阅，静态 ZIP/JSON/分享链接仍可继续使用；配置订阅不是升级的强制条件。

## 已验证范围

- Debian 13 amd64 单 VPS：从零安装、原位升级、回滚、重装、重启持久化、双协议实际连接；
- Windows 11：Clash Verge Rev `v2.5.2` / Mihomo `v1.19.29` 的订阅更新、节点切换与 Hysteria2 端口跳跃；v2rayN `v7.23.1` 的订阅导入与更新；
- Cloudflare Workers/KV：节点级发布身份、远端回读、Token 轮换/吊销和受管规则发布；
- Hysteria2 UDP buffer：本机 Debian 13 `apply → rollback → apply` 与真实 UDP socket 缓冲回读。

完整证据和边界见 [v0.2.0 实机验收报告](../V0.2.0_ACCEPTANCE.md) 与 [兼容性说明](../COMPATIBILITY.md)。

## 已知限制

- Debian 12、Ubuntu 24.04 和 arm64 未完成等价的 VPS 实机验收；
- Loon、Shadowrocket、Android 客户端、WARP、多 VPS 聚合与加密快照不属于本版本的通过范围；
- anti-AD 的真实误杀修复仍需在长期使用中按精确域名验证；不要把宽泛后缀或公网网段加入白名单；
- Hysteria2 的 Salamander、UDP buffer 和端口跳跃均默认关闭；端口跳跃还需要云安全组放行指定 UDP 范围；
- 不包含自定义 BBRv3 内核、Web 面板、多租户、流量计费或自动接管系统防火墙。
