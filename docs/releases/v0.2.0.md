# VPSKit v0.2.0

`v0.2.0` 为单 VPS 自动订阅版本：Cloudflare Workers/KV 负责客户端交付，VPS 仅使用节点级发布凭据，不持有 Cloudflare 账户级管理 Token。

主要能力：

- Mihomo 完整配置、v2rayN 节点订阅和 manifest 固定入口；
- `vpskit subscription plan/configure/publish/status`；
- 节点变更后的自动发布、远端回读、不可变修订和静态导出兜底；
- ETag、HEAD、条件 GET；
- 订阅读取 Token 的轮换、重叠和立即吊销；
- Worker/KV/Custom Domain 的受限部署脚本。

实机证据与范围见 [v0.2.0 自动订阅实机验收报告](../V0.2.0_ACCEPTANCE.md)。当前验收构建为 `v0.2.0-lab.1`；公开 Release 前仍须执行项目发布门禁。
