## 1. 结论

结论：`PASS`（本报告列出的 Debian 13 amd64、Cloudflare Workers/KV、Windows 11 客户端范围）。

`v0.2.0-lab.1` 已在一台 Debian 13 amd64 单 VPS 上完成升级。Cloudflare 预发布和正式订阅后端均已创建；正式后端由 VPS 的节点级发布凭据发布 `mihomo`、`v2rayn` 和 `manifest` 三类产物。Windows 11 上的 Clash Verge Rev 与 v2rayN 已由用户完成订阅导入和从 r0003 到 r0004 的手动“更新订阅”验收。

### 4.2 Windows 11 手动客户端验收

用户在 r0003 导入订阅 URL 后，执行客户端“更新订阅”。服务端将节点显示名修改为 `VPSKit-订阅-r0004` 并自动发布 r0004；用户确认以下两项均通过：

|---|---|
| Clash Verge Rev v2.5.2 / Mihomo v1.19.29 | 通过 |
| v2rayN v7.23.1 | 通过 |

静态 YAML/TXT 仅作为离线回退；客户端自动更新使用明确的 Mihomo 或 v2rayN 订阅 URL，不使用不稳定的 `auto` User-Agent 入口。

## 5. Token 轮换与吊销

正式订阅读取 Token 完成以下序列：

1. 轮换为新 Token，配置 24 小时重叠窗口；
2. 在重叠窗口内，旧 Token 与新 Token 均返回 `200`；
3. 通过 `revoke-read-token` 吊销初始 Token；
4. Workers KV 收敛后，旧 Token 返回 `404`，新 Token 保持 `200`。

这是最终一致性存储的预期语义：命令成功后存在短暂传播窗口；验收以“旧 Token 404、新 Token 200”收敛结果为准，不宣称全局瞬时原子吊销。

- VPS `/root` 下的临时发布包、临时节点凭据和客户端 Token 文件已删除；

## 7. 已知边界

- 当前客户端 GUI 证据绑定 Windows 11、Clash Verge Rev v2.5.2/Mihomo v1.19.29 和 v2rayN v7.23.1；
- Loon、Shadowrocket、Android 客户端、WARP、多 VPS 聚合、加密快照和长期资源观测不属于本次通过范围；
- Workers KV 为最终一致性，发布/回滚/Token 吊销均可能经历短暂传播窗口；

## 13. 后续增量：v0.2.9-lab.1 Hysteria2 受管 UDP buffer

1. 新命令为 `vpskit hysteria2 udp-buffer <status|plan|apply|rollback>`；当前唯一档位是 `conservative-2mib`，将 `net.core.rmem_default`、`net.core.wmem_default`、`net.core.rmem_max` 和 `net.core.wmem_max` 一并设为 `2097152`。
2. `plan` 和 `status` 不写入系统；`apply --profile conservative-2mib --yes` 会写入唯一受管 sysctl drop-in、保存原四项数值、重启 sing-box，并在 15 秒内读取 `ss -u -a -m -n` 的真实 `rb/tb`。若实际 socket 缓冲未达到目标或服务未恢复，将删除本次 drop-in、恢复四项数值并重启 sing-box。
3. `rollback --yes` 仅删除哈希仍匹配的 VPSKit drop-in，并恢复应用前四项数值；任何既有但非 VPSKit 所有的 sysctl 文件均拒绝替换。该功能不触及节点状态、客户端产物、规则或订阅，因此不应产生客户端配置修订。
4. 本地单元测试覆盖 profile 校验、sysctl 渲染与实际 `ss` 输出解析。Debian 13 amd64 已先将旧实验配置恢复至记录的四项 `212992` 基线，再完成 `apply/status/rollback/apply`；最终 `rb/tb=2097152`、Xray/sing-box active、状态与订阅摘要不变、orphan scan 无新增项。该系统参数不影响客户端订阅，本轮不需要用户重新导入或切换节点；仅建议后续按同一测速条件进行稳定性观察。
